# Invented

Every element made for the game, one row each: what it is, why the game needed it, and which borrowed element it sits beside (see `borrowed.md`). Invented elements may be changed, with a reason. Later chapters add rows.

Rows marked **stretch** push a borrowed element further than its source states. They are the first to revisit if the source changes.
